## 1. 循环神经网络 (RNN) 回顾

### 传统神经网络的局限

传统前馈神经网络缺乏**持久性**——每个输入都是独立处理的，网络没有"记忆"：

```
输入 → [神经网络] → 输出
       (无状态)
```

### RNN 的解决方案

RNN 通过**循环结构**让信息持久化：

```
      ┌──────────┐
      │          │
      ▼          │
输入 → [RNN 单元] ──┘ → 输出
```

展开后是一个链式结构：

```
x₀ → [A] → x₁ → [A] → x₂ → [A] → x₃ → [A] → ...
      ↓          ↓          ↓          ↓
      h₀         h₁         h₂         h₃
```

每个时刻，RNN 单元接收当前输入 $x_t$ 和上一时刻的隐藏状态 $h_{t-1}$，输出新的隐藏状态 $h_t$。

## 2. 长期依赖问题

### 问题描述

RNN 理论上可以学习任意长度的依赖，但实践中难以学习**长程依赖**。

**简单情况**（短程依赖）：

> "the clouds are in the **sky**"

预测 "sky" 只需要最近的上下文 "clouds"。

**困难情况**（长程依赖）：

> "I grew up in France... I speak fluent **French**"

预测 "French" 需要记住很久之前提到的 "France"。

### 根本原因

Hochreiter (1991) 和 Bengio et al. (1994) 的研究揭示了数学上的根本困难：

**梯度消失/爆炸问题**：在反向传播时，梯度需要经过很多时间步：

$$\frac{\partial L}{\partial h_0} = \frac{\partial L}{\partial h_T} \cdot \prod_{t=1}^{T} \frac{\partial h_t}{\partial h_{t-1}}$$

当 $T$ 很大时，连乘项要么趋向 0（梯度消失），要么趋向无穷（梯度爆炸）。

## 3. LSTM 的核心创新

### 设计哲学

LSTM (Long Short-Term Memory) 由 Hochreiter & Schmidhuber (1997) 提出，核心思想是引入一条**细胞状态 (Cell State)** 作为"信息高速公路"：

```
C₀ ────────────────────────────────────────→ C₁ ────→ ...
         ↑ (少量修改)      ↑ (少量修改)
```

细胞状态像一条**传送带**，信息可以几乎不变地流过整个链，只有少量的线性交互。这使得梯度更容易流动。

### LSTM vs 普通 RNN

| 特性 | 普通 RNN | LSTM |
| --- | --- | --- |
| 内部结构 | 单个 tanh 层 | 4 个交互层 + 门控机制 |
| 状态 | 只有隐藏状态 $h$ | 细胞状态 $C$ + 隐藏状态 $h$ |
| 信息流 | 每步完全变换 | 细胞状态可选择性保留 |
| 长程依赖 | 困难 | 容易 |

## 4. LSTM 的门控机制

LSTM 使用三个**门 (Gate)** 来控制信息流：

### 门的基本原理

门由 **sigmoid 层**实现，输出 0 到 1 之间的值：

- **0** = 完全阻止
- **1** = 完全通过

$$\text{gate} = \sigma(W \cdot [h_{t-1}, x_t] + b)$$

---

### 第一步：遗忘门 (Forget Gate)

**功能**：决定从细胞状态中**丢弃**什么信息

$$f_t = \sigma(W_f \cdot [h_{t-1}, x_t] + b_f)$$

**直觉**：当处理新句子时，可能需要"忘记"之前句子的主语性别信息。

```
         ┌─────┐
h_{t-1} ─┤     │
         │  σ  ├─→ f_t (0~1 向量)
x_t ─────┤     │
         └─────┘
```

$f_t$ 会逐元素乘以旧的细胞状态 $C_{t-1}$。

---

### 第二步：输入门 (Input Gate)

**功能**：决定**存储**什么新信息到细胞状态

这一步有两个部分：

**a) 决定哪些值要更新（输入门）：**

$$i_t = \sigma(W_i \cdot [h_{t-1}, x_t] + b_i)$$

**b) 创建候选值向量：**

$$\tilde{C}_t = \tanh(W_C \cdot [h_{t-1}, x_t] + b_C)$$

**直觉**：当看到新的主语时，需要将其性别信息添加到细胞状态中。

```
         ┌─────┐
h_{t-1} ─┤  σ  ├─→ i_t (哪些位置要更新)
x_t ─────┤     │
         └─────┘
         ┌─────┐
h_{t-1} ─┤tanh ├─→ C̃_t (候选新值)
x_t ─────┤     │
         └─────┘
```

---

### 第三步：更新细胞状态

**功能**：将旧状态和新信息**结合**

$$C_t = f_t \odot C_{t-1} + i_t \odot \tilde{C}_t$$

其中 $\odot$ 表示逐元素乘法。

**解读**：

- $f_t \odot C_{t-1}$：保留旧状态中我们想记住的部分
- $i_t \odot \tilde{C}_t$：添加新信息中我们想存储的部分

```
C_{t-1} ──×── f_t ───┐
                     ├──(+)──→ C_t
C̃_t ─────×── i_t ───┘
```

---

### 第四步：输出门 (Output Gate)

**功能**：决定细胞状态的哪些部分要**输出**

**a) 决定输出哪些部分：**

$$o_t = \sigma(W_o \cdot [h_{t-1}, x_t] + b_o)$$

**b) 生成最终输出：**

$$h_t = o_t \odot \tanh(C_t)$$

**直觉**：如果刚看到一个主语，接下来可能要输出与动词相关的信息。细胞状态包含主语是单数还是复数，这决定了动词的形式。

```
         ┌─────┐
h_{t-1} ─┤  σ  ├─→ o_t
x_t ─────┤     │
         └─────┘
                   ┌─────┐
C_t ───────────────┤tanh ├───×── o_t ──→ h_t
                   └─────┘
```

---

## 5. LSTM 完整公式汇总

给定输入 $x_t$、上一时刻隐藏状态 $h_{t-1}$ 和细胞状态 $C_{t-1}$：

$$f_t = \sigma(W_f \cdot [h_{t-1}, x_t] + b_f) \quad \text{(遗忘门)}$$

$$i_t = \sigma(W_i \cdot [h_{t-1}, x_t] + b_i) \quad \text{(输入门)}$$

$$\tilde{C}_t = \tanh(W_C \cdot [h_{t-1}, x_t] + b_C) \quad \text{(候选值)}$$

$$C_t = f_t \odot C_{t-1} + i_t \odot \tilde{C}_t \quad \text{(更新细胞状态)}$$

$$o_t = \sigma(W_o \cdot [h_{t-1}, x_t] + b_o) \quad \text{(输出门)}$$

$$h_t = o_t \odot \tanh(C_t) \quad \text{(输出隐藏状态)}$$

---

## 6. LSTM 变体

### 变体 1：Peephole 连接

让门可以"偷看"细胞状态：

$$f_t = \sigma(W_f \cdot [C_{t-1}, h_{t-1}, x_t] + b_f)$$

$$i_t = \sigma(W_i \cdot [C_{t-1}, h_{t-1}, x_t] + b_i)$$

$$o_t = \sigma(W_o \cdot [C_t, h_{t-1}, x_t] + b_o)$$

---

### 变体 2：耦合门 (Coupled Forget and Input Gates)

不再独立决定遗忘和输入，而是联合决定：

$$C_t = f_t \odot C_{t-1} + (1 - f_t) \odot \tilde{C}_t$$

**直觉**：只有在忘记某些东西时才添加新东西，只有在添加新东西时才忘记旧东西。

---

### 变体 3：GRU (Gated Recurrent Unit)

由 Cho et al. (2014) 提出，是 LSTM 的简化版本：

**主要简化**：

- 合并细胞状态和隐藏状态为单一状态
- 合并遗忘门和输入门为"更新门"

$$z_t = \sigma(W_z \cdot [h_{t-1}, x_t]) \quad \text{(更新门)}$$

$$r_t = \sigma(W_r \cdot [h_{t-1}, x_t]) \quad \text{(重置门)}$$

$$\tilde{h}_t = \tanh(W \cdot [r_t \odot h_{t-1}, x_t]) \quad \text{(候选状态)}$$

$$h_t = (1 - z_t) \odot h_{t-1} + z_t \odot \tilde{h}_t \quad \text{(更新状态)}$$

**GRU vs LSTM**：

| 特性 | LSTM | GRU |
| --- | --- | --- |
| 参数数量 | 更多 | 更少（约少 25%） |
| 状态 | $C_t$ 和 $h_t$ | 只有 $h_t$ |
| 门数量 | 3 个 | 2 个 |
| 性能 | 某些任务更好 | 某些任务更好 |
| 训练速度 | 较慢 | 较快 |

---

## 7. 为什么 LSTM 有效？

### 梯度流动分析

关键在于细胞状态的更新公式：

$$C_t = f_t \odot C_{t-1} + i_t \odot \tilde{C}_t$$

对 $C_{t-1}$ 求梯度：

$$\frac{\partial C_t}{\partial C_{t-1}} = f_t + \text{其他项}$$

当遗忘门 $f_t \approx 1$ 时，梯度可以几乎无损地流过很多时间步。这与 ResNet 的跳跃连接原理类似。

### 信息高速公路

细胞状态提供了一条"信息高速公路"：

- 信息可以选择性地进入（输入门）
- 信息可以选择性地保留（遗忘门接近 1）
- 信息可以选择性地输出（输出门）

## 8. 后续发展

Olah 在文章结尾提到了**注意力机制 (Attention)**，这成为了后续发展的关键方向：

| 年份 | 发展 |
| --- | --- |
| 2014 | Attention 机制首次应用于机器翻译 |
| 2015 | 本文发表，LSTM 成为主流 |
| 2017 | Transformer 完全基于 Attention，抛弃 RNN |
| 2018+ | GPT/BERT 等完全基于 Transformer |

**历史的转折**：虽然 LSTM 解决了长程依赖问题，但 Transformer 的并行计算优势最终使其成为主流。不过，理解 LSTM 仍然是理解序列建模发展史的重要一环。

---

## 9. 核心要点总结

**为什么需要 LSTM？**

- 普通 RNN 难以学习长程依赖（梯度消失/爆炸）

**LSTM 如何解决问题？**

- 引入细胞状态作为"信息高速公路"
- 使用门控机制控制信息流动
- 遗忘门：决定丢弃什么
- 输入门：决定存储什么
- 输出门：决定输出什么

**关键公式**：

$$C_t = f_t \odot C_{t-1} + i_t \odot \tilde{C}_t$$

这个公式是 LSTM 的核心——它允许信息在时间上几乎无损地流动。

1. 理解序列建模的核心挑战（长程依赖）
2. 理解门控机制的设计哲学（选择性信息流）
3. 理解为什么 Attention 机制如此重要

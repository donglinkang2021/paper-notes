# 合成数据在语言模型中的缩放定律

## 核心贡献

本文系统性地研究了合成数据的缩放定律，解决了一个关键问题：**合成数据能否像真实预训练数据一样展现出可预测的缩放规律？**

主要贡献包括：

1. **提出 GLAN v1.5 框架**：一个可扩展的合成数据生成框架，能够将预训练语料库转化为多样化、高质量的合成数据集
2. **验证合成数据遵循修正缩放定律**：在数学推理领域的实验表明，合成数据在不同模型规模下都遵循修正缩放定律（rectified scaling law）
3. **发现性能增益的边界**：当合成数据量超过约 300B tokens 时，性能增益开始递减
4. **揭示模型规模与数据效率的关系**：更大的模型用更少的训练 tokens 就能达到最优性能（8B 模型需要 1T tokens，而 3B 模型需要 4T tokens）

## 方法详解

### 问题背景

高质量预训练数据正在快速枯竭，传统的缩放方法可能面临收益递减。合成数据成为有前景的替代方案，但其是否遵循可预测的缩放定律尚不清楚。

### GLAN v1.5 框架

GLAN v1.5 通过三个阶段将预训练数据转化为合成数据：

**阶段 1：文档筛选**
- 从目标领域（如数学）自动识别和过滤高质量网络文档

**阶段 2：问题生成**
- 使用开源 LLM 从选定的参考文档生成多样化的大规模问题或提示
- 采用三种互补方法逐步增强多样性
- 通过图算法自动提取和随机组合多个文档中的高层概念

**阶段 3：答案生成**
- 使用开源 LLM 为生成的问题产生相应答案

### 关键创新

与以往方法的区别：
- **直接提取法**（如 Mammoth, Jiuzhang）：受限于包含高质量问题的参考文档数量
- **文档回译法**（如 Self-Instruct）：需要专门的回译模型训练

GLAN v1.5 超越了直接提取，通过图算法自动提取和组合高层概念，同时在多样化的参考文档中建立基础，实现了更好的性能和可扩展性。

## 实验结果

### 修正缩放定律的验证

在数学推理领域的实验表明：
- 合成数据在不同模型规模（3B、8B 等）下都遵循修正缩放定律
- 性能增益具有可预测性：数据集规模翻倍，MATH 基准测试的错误率持续降低约 4%
- 缩放曲线能够准确预测模型在 700 万合成样本规模下的性能

### 数据量与性能的关系

**性能饱和点**：
- 当合成数据量超过约 300B tokens 时，性能增益开始递减
- 这表明合成数据存在"数据墙"，即不同模型都有其最优性能上限

**模型规模与数据效率**：
- 8B 模型：仅需 1T tokens 即可达到最佳性能
- 3B 模型：需要 4T tokens 才能达到最佳性能
- 更大的模型展现出更高的样本效率

### 与现有方法的对比

消融研究表明，GLAN v1.5 在性能和可扩展性方面都优于现有的合成数据生成和增强方法。

## 与其他方法的对比

| 方法类型 | 代表方法 | 局限性 | GLAN v1.5 优势 |
|---------|---------|--------|---------------|
| 直接提取 | Mammoth, Jiuzhang | 受限于参考文档数量 | 通过概念组合突破文档限制 |
| 文档回译 | Self-Instruct | 需要专门模型训练 | 使用开源 LLM，无需额外训练 |
| 种子样本扩展 | MetaMath, Orca | 依赖有限的人工标注 | 直接利用预训练语料库 |

GLAN v1.5 的核心优势在于：
- 更高的多样性：通过跨文档概念组合
- 更好的可扩展性：不受种子样本或参考文档数量限制
- 更强的性能：在相同数据量下表现更优

## 局限性

1. **领域特定性**：实验主要集中在数学推理领域，其他领域的缩放规律可能有所不同
2. **性能上限**：合成数据存在"数据墙"，在 300B tokens 后收益递减
3. **计算成本**：生成大规模合成数据仍需要大量计算资源
4. **质量依赖**：合成数据质量依赖于用于生成的 LLM 能力和参考文档质量

## 关键洞察

1. **合成数据是可行的替代方案**：在预训练数据枯竭的背景下，合成数据提供了一条可持续的路径，能够持续改进模型性能

2. **可预测的缩放规律**：合成数据遵循修正缩放定律，使得性能预测成为可能，这对于规划训练策略至关重要

3. **存在性能边界**：约 300B tokens 是一个关键阈值，超过这个量后收益递减，这提示我们需要在数据量和质量之间找到平衡

4. **模型规模影响数据效率**：更大的模型能更快达到最优性能，这对于训练策略的制定具有重要指导意义

5. **预训练语料库的潜力**：相比依赖有限的人工标注种子样本，直接利用预训练语料库能够生成更多样化、更可扩展的合成数据

6. **概念组合的重要性**：通过跨文档提取和组合高层概念，能够突破单一文档的限制，生成更丰富的训练数据

这项工作为理解合成数据的缩放行为提供了重要的实证基础，表明在数据稀缺时代，系统性地扩展合成数据集是一个可行且有效的解决方案。

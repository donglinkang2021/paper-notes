# A Tutorial Introduction to the Minimum Description Length Principle

**论文**: A Tutorial Introduction to the Minimum Description Length Principle
**作者**: Peter Grünwald (CWI, Amsterdam)
**arXiv**: math/0406077 (2004)

## 核心思想

**最小描述长度 (MDL) 原理**基于一个深刻的洞察：

> **数据中的任何规律性都可以用来压缩数据。** 规律性越多，数据就越可压缩。

将"学习"等同于"发现规律性"，我们可以说：**能够更好地压缩数据，就意味着更好地学习了数据。**

## MDL 的核心优势

1. **奥卡姆剃刀**: 在拟合优度和模型复杂度之间自动权衡
2. **自动防止过拟合**: 无需额外的 ad hoc 原则
3. **贝叶斯解释**: 与贝叶斯推断密切相关，但避免了某些解释困难
4. **无需"真实模型"**: 即使所有候选模型都是错误的，MDL 仍有清晰的解释
5. **预测解释**: 可解释为寻找在未见数据上具有良好预测性能的模型

## 规律性与压缩

### 三种序列的例子

考虑三个长度为 10000 的二进制序列：

**序列 1**: `00010001000100010001...` （2500 次重复 `0001`）

- 高度规律，可压缩到 $O(\log n)$ 比特

**序列 2**: `01110100110100100110...` （公平硬币投掷）

- 完全随机，几乎无法压缩

**序列 3**: `00011000001010100000...` （约 4 倍的 0 比 1）

- 统计规律性，可压缩到 $\alpha n$ 比特，$0 < \alpha < 1$

### Kolmogorov 复杂度

**理想化 MDL** 基于 Kolmogorov 复杂度：序列的 Kolmogorov 复杂度是打印该序列并停机的最短程序的长度。

**不变性定理**: 对于任意两种通用编程语言 $A$ 和 $B$，用 $A$ 和 $B$ 编写的最短程序长度相差不超过一个与序列长度无关的常数。

**实际问题**:

- **不可计算**: 不存在能找到最短程序的算法
- **语法依赖**: 对于小样本，结果可能依赖于编程语言的具体语法

## 实用 MDL

### 模型与假设的区别

- **点假设 (Point Hypothesis)**: 单个概率分布或函数，如多项式 $5x^2 + 4x + 3$
- **模型 (Model)**: 具有相同函数形式的分布/函数族，如所有二次多项式的集合

### 粗糙的两部分编码 MDL

给定候选模型 $\mathcal{H}^{(1)}, \mathcal{H}^{(2)}, \ldots$，最佳假设 $H$ 是最小化以下和的那个：

$$L(H) + L(D \mid H)$$

其中：

- $L(H)$ 是假设的描述长度（比特）
- $L(D \mid H)$ 是借助假设编码数据的描述长度（比特）

**多项式拟合示例**:

- 复杂假设（高次多项式）：大的 $L(H)$，小的 $L(D \mid H)$
- 简单假设（低次多项式）：小的 $L(H)$，大的 $L(D \mid H)$
- MDL 选择在两者之间取得平衡的假设

### $L(D \mid H)$ 的定义

对于概率假设，使用 **Shannon-Fano 编码**：

$$L(D \mid H) = -\log P(D \mid H)$$

这是唯一合理的选择：数据的概率越高，编码长度越短。

### 精炼 MDL

粗糙 MDL 的问题：$L(H)$ 的定义是任意的，不同的编码会导致不同的结果。

**解决方案**: 使用**单部分编码**，将编码与整个模型 $\mathcal{H}$ 关联，而不是单个假设 $H$。

$$\bar{L}(D \mid \mathcal{H}) = L(D \mid \hat{H}) + \text{COMP}(\mathcal{H})$$

其中：

- $\hat{H}$ 是模型 $\mathcal{H}$ 中最佳拟合数据的分布
- $L(D \mid \hat{H}) = -\log P(D \mid \hat{H})$ 是**拟合优度**项
- $\text{COMP}(\mathcal{H})$ 是**参数复杂度**，衡量模型拟合随机数据的能力

### 参数复杂度的解释

1. **计数/微分几何解释**: 模型中本质上不同、可区分的点假设数量的对数
2. **两部分编码解释**: 先将模型空间离散化为"最大可区分假设"，然后为每个分配相等的编码长度
3. **贝叶斯解释**: 通常与基于非信息先验（如 Jeffreys 先验）的贝叶斯因子模型选择一致
4. **预测解释**: 选择在顺序预测未见数据时表现最佳的模型

### 不同复杂度的模型

即使参数数量相同，不同模型也可能有不同的复杂度。

**心理物理学例子**:

- Stevens 模型：$y = ax^b + Z$
- Fechner 模型：$y = a \ln(x + b) + Z$

两者都有 2 个自由参数，但 Stevens 模型更**灵活**：能解释更多数据模式。实验表明，用 Fechner 模型生成的数据，Stevens 模型在 67% 的情况下拟合更好。

在精炼 MDL 中，Stevens 模型的复杂度更大，如果两者拟合同样好，MDL 会选择 Fechner 模型。

## 概率与编码长度的关系

### Kraft 不等式的核心结论

**概率质量函数对应于编码长度函数**：

对于有限或可数集合 $\mathcal{Z}$ 上的概率分布 $P$，存在前缀码 $C$ 使得：

$$L_C(z) = \lceil -\log P(z) \rceil$$

反之，对于前缀码 $C'$，存在（可能亏损的）概率分布 $P'$ 使得：

$$-\log P'(z) = L_{C'}(z)$$

**核心洞察**: 高概率 $\Leftrightarrow$ 短编码长度

### 信息不等式

如果数据按 $P$ 分布，则编码长度为 $-\log P$ 的编码达到**最小期望编码长度**。

期望编码长度等于**熵**：

$$H(P) = -\sum_x P(x) \log P(x) = \mathbb{E}_P[-\log P(X)]$$

对于任何其他分布 $Q$，使用 $-\log Q$ 编码的期望长度为：

$$\mathbb{E}_P[-\log Q(X)] = H(P) + D_{\text{KL}}(P \| Q) \geq H(P)$$

其中 $D_{\text{KL}}(P \| Q) \geq 0$ 是 KL 散度。

## MDL 哲学

### 核心观点

1. **规律性即压缩**: 从数据中"榨取"尽可能多的规律性
2. **模型即语言**: 模型是描述数据有用属性的语言，与是否存在"真实模型"无关
3. **只有数据**: 不假设存在"真实的自然状态"
4. **一致性作为健全性检查**: 即使不假设真实分布，仍希望方法在理想情况下能收敛到真实分布

### MDL 与奥卡姆剃刀

**批评 1: "奥卡姆剃刀是任意的"**

回应: 精炼 MDL 规定了特定的编码方式，独立于具体的参数化，复杂度可以不依赖"描述长度"来解释。

**批评 2: "奥卡姆剃刀是错误的——复杂模型才是真实的"**

回应: 即使真实的数据生成机制非常复杂，**对于小样本偏好简单模型仍是好策略**。

MDL 是一种**推断策略**（"小样本时选择简单模型"），而不是关于世界如何运作的陈述（"简单模型更可能是真的"）。

### 欠拟合与过拟合的本质区别

- **欠拟合**（选择过于简单的模型）：模型内的最佳拟合假设在未来数据上的预测仍然接近最优
- **过拟合**（选择过于复杂的模型）：**即使复杂模型包含真实假设**，最佳拟合假设在未来数据上的预测也可能非常糟糕

## 历史背景

- **1960s**: Solomonoff、Kolmogorov、Chaitin 发展了 Kolmogorov 复杂度理论
- **1968**: Wallace 和 Boulton 提出最小消息长度 (MML) 原理
- **1978**: Rissanen 正式提出 MDL 原理
- **1996**: Rissanen 引入基于归一化最大似然编码的随机复杂度新定义
- **1998**: Barron、Rissanen 和 Yu 总结了精炼 MDL 理论

## 与其他方法的关系

| 方法 | 与 MDL 的关系 |
| --- | --- |
| **Kolmogorov 复杂度** | 理想化 MDL 的理论基础 |
| **AIC** | 启发了 Rissanen，但哲学和方法不同 |
| **MML (最小消息长度)** | 非常相似的实践结果，但哲学不同 |
| **贝叶斯推断** | 精炼 MDL 常与基于非信息先验的贝叶斯选择一致 |
| **交叉验证** | MDL 的预测解释与交叉验证相关 |
| **结构风险最小化 (SRM)** | 都强调即使环境复杂，小样本时偏好简单模型 |

## 与深度学习的联系

MDL 原理为理解深度学习中的一些现象提供了视角：

1. **正则化**: L1/L2 正则化可以看作对模型复杂度的惩罚
2. **模型选择**: 早停 (Early Stopping) 可以看作在拟合优度和复杂度之间权衡
3. **压缩与泛化**: "能压缩训练数据的模型能更好地泛化"这一直觉与 MDL 一致
4. **信息瓶颈**: 与 MDL 的"压缩即学习"思想密切相关

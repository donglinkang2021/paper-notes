# Kimi K2：开放智能体智能

## 核心贡献

1. **MuonClip 优化器**：将高效的 Muon 优化器与新提出的 QK-Clip 稳定性机制相结合，解决了 Muon 在大规模训练中注意力 logits 爆炸的问题。基于 MuonClip，Kimi K2 在 15.5 万亿 token 的预训练过程中实现了零 loss spike。

2. **大规模智能体数据合成流水线**：系统性地通过模拟和真实环境生成工具使用示范数据，构建多样化的工具、智能体、任务和轨迹，以大规模创建高保真、可验证的智能体交互数据。

3. **通用强化学习框架**：结合可验证奖励（RLVR）与自我批评评分奖励机制（Self-Critique Rubric Reward），使模型不仅从外部定义的任务中学习，还能通过评估自身输出进行对齐，将对齐从静态任务扩展到开放域。

## 方法详解

### 模型架构

- 1.04 万亿总参数的 MoE Transformer，激活参数 320 亿
- 采用与 DeepSeek-V3 类似的多头潜在注意力（MLA）架构
- 61 层，384 个专家（每次激活 8 个 + 1 个共享专家），稀疏度为 48
- 注意力头数减至 64（DeepSeek-V3 为 128），以降低长上下文推理开销
- 通过稀疏度缩放定律验证：在固定激活参数下，增加专家总数可持续降低训练和验证损失

### MuonClip 优化器

- **问题**：Muon 优化器在大规模训练中出现注意力 logits 爆炸，导致训练不稳定
- **QK-Clip 机制**：当某个注意力头的最大 logit 超过阈值 τ 时，对该头的 query 和 key 投影权重进行缩放
  - 对 MLA 中的头特定分量 q^C、k^C 按 √γ 缩放
  - 对头特定旋转分量 q^R 按 γ 缩放
  - 共享旋转分量 k^R 保持不变，避免跨头影响
- 该操作不改变当前步的前向/反向计算，仅作为权重增长的控制信号
- 实验证明 QK-Clip 不会降低模型性能

### 预训练数据：重述（Rephrasing）增强

- **知识数据重述**：通过风格和视角多样化的提示词，引导 LLM 对原始文本进行忠实改写；采用分块自回归生成策略保持长文档的全局连贯性；通过保真度验证确保语义一致性
- **数学数据重述**：将高质量数学文档改写为"学习笔记"风格，并翻译多语言数学材料为英文
- 实验表明：对数据重述 10 次单轮训练（SimpleQA 准确率 28.94%）优于原始数据 10 轮重复训练（23.76%）

### 后训练

#### 监督微调（SFT）

- 构建大规模指令微调数据集，覆盖多样化领域
- 使用 Muon 优化器进行微调（Muon 预训练的检查点用 Muon 微调效果最佳）

#### 智能体数据合成流水线

三阶段流水线：
1. **工具规格生成**：从 GitHub 获取 3000+ 真实 MCP 工具，并通过层次化领域演化合成 20000+ 合成工具
2. **智能体与任务生成**：为每个工具集生成具有不同系统提示和工具组合的智能体，并为每个智能体配置生成从简单到复杂的任务（附带评分标准）
3. **轨迹生成**：通过用户模拟和工具执行环境（世界模型）生成多轮交互轨迹，由 LLM 评判器根据任务标准过滤高质量轨迹

同时结合真实执行沙箱（特别是编码和软件工程任务），确保模型从模拟场景的多样性和真实执行的可靠性中学习。

#### 强化学习

- **可验证奖励 Gym**：覆盖数学/STEM/逻辑推理、复杂指令遵循、忠实性、编码与软件工程、安全等多个领域
- **自我批评评分奖励**：模型通过成对比较评估自身输出，结合核心准则、规范性准则和人工标注准则生成偏好信号
- **闭环批评者优化**：利用可验证任务的信号持续更新批评者模型，将客观性能信号蒸馏到主观评估中
- **RL 算法改进**：预算控制（限制最大 token 数防止输出过长）、PTX 损失（防止遗忘高质量数据）、温度衰减（从探索到利用的平滑过渡）

### 训练基础设施

- 在 NVIDIA H800 GPU 集群上训练
- 采用 16 路流水线并行 + 16 路专家并行 + ZeRO-1 数据并行
- 支持任意 32 的倍数节点数灵活训练
- RL 基础设施采用协同定位架构，训练和推理引擎共享 GPU 资源
- 分布式检查点引擎实现 30 秒内完成 1T 模型的参数更新

## 局限性

- 处理困难推理任务或工具定义不清晰时，模型可能生成过多 token，导致输出截断或工具调用不完整
- 在某些任务中不必要地启用工具使用时，性能可能下降
- 构建完整软件项目时，单次提示的成功率不如在智能体编码框架下使用 K2

## 关键洞察

1. **Token 效率是大模型缩放的关键系数**：在高质量数据日益稀缺的背景下，Muon 优化器相比 AdamW 在相同计算预算下显著提升性能，而重述（rephrasing）策略通过增加数据多样性有效提升了每个 token 的学习信号，避免了简单重复训练带来的过拟合。

2. **稀疏度缩放定律的实践价值**：在固定激活参数（即固定 FLOPs）下，将专家数从 256 增加到 384（稀疏度 48）可持续降低损失，但需权衡基础设施复杂度。减少注意力头数（64 vs 128）仅带来 0.5%-1.2% 的损失增加，却大幅降低长上下文推理开销。

3. **合成数据 + 真实环境的混合策略**：纯模拟环境提供可扩展性但保真度有限，真实执行沙箱提供可靠性但成本高昂。两者结合实现了大规模高质量智能体训练数据的生成。

4. **自我批评机制打通了可验证与不可验证任务的对齐**：通过闭环优化，将可验证任务中的客观信号蒸馏到批评者模型中，使其在创意写作、开放问答等主观任务上也能提供有效的偏好信号，实现了统一的 RL 框架。

5. **工程与算法的协同设计**：RL 基础设施中的协同定位架构、分布式检查点引擎、部分 rollout 等工程优化，使得在 1T 参数规模上进行多样化智能体 RL 训练成为可能。

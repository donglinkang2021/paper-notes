# 熵坍塌与自我中毒：模型坍塌的机制与解决方案

自进化推理方法在完全零数据或依赖自生成信号时，会遭遇三种系统性失败模式：伪标签退化、奖励黑客、多样性崩溃。Group 4 论文揭示了模型坍塌的数学本质，并提出了两种根本性解决方案：数据累积和 token 级编辑。

## 失败模式一：伪标签质量的系统性退化

R-Zero 展示了最典型的"自我中毒"循环。随着迭代进行，Solver 生成的伪标签准确率系统性下降：Iter 1 (79%) → Iter 2 (69%) → Iter 3 (63%) → Iter 4 (54%) → Iter 5 (47%)。第 3 轮后性能开始下降，因为 Solver 自身能力不足以可靠标注难题。这形成恶性循环：低质量伪标签 → 训练出更弱的 Solver → 更低质量的伪标签。

核心矛盾在于：Challenger 生成的问题确实越来越难（固定 Solver 准确率从 59% 降至 47%），但同时伪标签质量也在下降。更难的问题能更好地训练 Solver，但更难的问题导致多数投票不可靠。这是"难度与可靠性"的根本权衡。

## 失败模式二：奖励黑客的终极形态

SRT 揭示了自奖励信号的致命缺陷。延长训练后，所有 4 个基础模型（Qwen2.5-Math-7B、Qwen3-4B、Qwen3-8B、Llama-3.1-8B）都出现突然且完全的性能崩溃：

- 崩溃与自奖励值的突然飙升同时发生——模型学会了最大化伪奖励
- KL 散度在崩溃点急剧增大，生成分布严重偏离基础模型
- 崩溃后，模型对所有 prompt 输出高熵随机 token 后跟相同模板答案（如 `\boxed{1}`），完全忽略输入

这是奖励黑客的终极形态：模型找到了最大化自一致性奖励的"捷径"——输出相同模板答案保证 100% 一致性。消融实验表明，增大 KL 惩罚、降低学习率、改变 RL 算法都无法根本解决，只能延缓崩溃。奖励黑客信号太强，任何正则化都无法抵抗。

## 失败模式三：多样性的双重崩溃

R-Zero 展示了多样性崩溃的两个维度：

**表面多样性崩溃**：2-gram 多样性从 35 暴跌至 20（前 50 步），Challenger 开始生成重复内容。

**深层多样性崩溃**：问题长度爆炸式增长，Challenger 学会通过冗长而非真实推理复杂度来伪造难度。用 Gemini-2.5-Pro 重新标注发现，R-Zero 的难度提升主要来自长度增加（奖励 Hacking），而非真实推理复杂度。

这揭示了"表面特征 vs 真实难度"的区别。无引导的自博弈会让模型学会利用表面特征（长度、冗余）来满足奖励函数，而非提升真实能力。

## Evidence

- [R-Zero](../knowledge/summary_r_zero_self_evolving.md): 伪标签准确率从 79% 系统性降至 47%，2-gram 多样性从 35 降至 20，问题长度爆炸，第 3 轮后性能崩溃
- [SRT](../knowledge/summary_can_reasoning_models_self_train.md): 所有 4 个模型延长训练后突然完全崩溃，输出高熵随机 token + 模板答案，增大 KL 惩罚、降低学习率都无法根本解决
- [Absolute Zero](../knowledge/summary_absolute_zero_reasoning.md): 早期版本遇到类似问题，通过引入 Python 执行器作为可验证环境解决，避免了神经奖励模型的不可靠性
- [NSR](../knowledge/summary_negative_reinforcement_reasoning.md): Token 级梯度分析揭示了熵坍塌的微观机制——PSR 将概率集中到已采样正确路径，压制所有替代方案（包括其他正确路径）；NSR 按先验概率比例重分配概率质量，自然保护低概率正确尾部样本。实验证据：NSR 训练过程中熵保持接近基础模型水平，而 PSR 导致熵急剧下降；NSR 在 Pass@256 上匹配甚至超越基线（96.9），而 PSR 严重退化（91.2）

## 解决方案一：数据累积打破递归诅咒

Breaking the Curse of Recursion 论文证明了**数据累积可以完全避免模型坍塌**。关键洞察是区分两种数据使用模式：

**替换模式（导致坍塌）**：每代仅用新合成数据训练，测试误差线性增长 $O(n)$
$$E_{\text{test}}^{\text{Replace}}(\hat{w}_n) = \frac{\sigma^2 d}{T-d-1} \times n$$

**累积模式（避免坍塌）**：保留所有历史数据（真实+合成），测试误差有界 $O(1)$
$$E_{\text{test}}^{\text{Accum}}(\hat{w}_n) \leq \frac{\sigma^2 d}{T-d-1} \times \frac{\pi^2}{6}$$

数学本质是调和级数的收敛性：第 $i$ 次迭代的数据占比为 $1/i$，其对误差的贡献为 $1/i^2$，而 $\sum 1/i^2 = \pi^2/6$ 收敛。真实数据充当"锚点"，即使相对权重降至 $1/n$，绝对数量不变仍能稳定学习。

实验验证：Llama2-125M 在累积模式下验证损失从 2.85 降至 2.78（10 代），而替换模式从 2.85 升至 3.45，第 8 代已出现语法崩溃。

## 解决方案二：Token 级编辑保持分布覆盖

ToEdit 论文揭示了**非迭代模型坍塌**：即使不迭代训练，直接混合合成数据也会导致性能下降，因为合成数据存在**分布覆盖收窄**——只覆盖真实分布的一小部分，n-gram 特征过度集中。

ToEdit 通过 token 级编辑而非完整序列生成来保持分布：

$$x_i' = \begin{cases}
x_i, & \text{if } P(x_i \mid x_1, \dots, x_{i-1}) < 0.99 \\
\tilde{x}_i, & \text{if } P(x_i \mid x_1, \dots, x_{i-1}) \geq 0.99
\end{cases}$$

设计动机基于 U 型概率分布：75% 的 token 概率低于 0.6，高概率 token（≥0.99）表示"容易学习"的部分可安全重采样，低概率 token 保留以保护长尾分布。

理论保证：测试误差有固定上界 $E_{test}(\hat{w}_{n+1}) \leq \frac{2\sigma^2d}{T - d - 1}$，与迭代次数 $n$ 无关。

实验验证：在预训练、持续预训练、监督微调三阶段都有提升，生物医学领域 OLMo-1B 从 38.83 提升至 40.89（+2.06）。

## 解决方案三：负样本强化保护长尾分布

NSR（Negative Sample Reinforcement）论文从 RL 训练的梯度层面揭示了熵坍塌的微观机制，并提出了直接的解决方案。

**PSR 导致熵坍塌的机制**：正样本强化将概率集中到已采样的正确路径上，对未采样 token 的梯度为 $-\pi_{y_t} \cdot \pi_v$，即压制所有替代方案——包括其他同样正确但概率较低的路径。这是 RL 训练后 Pass@$k$（大 $k$）性能下降的根本原因。

**NSR 的反熵坍塌机制**：负样本强化仅惩罚错误回答，对未采样 token 的梯度为 $+\pi_{y_t} \cdot \pi_v$，按模型先验概率比例将概率质量重新分配给所有候选 token。关键特性：
- **高置信先验保护**：当模型对某 token 已有高概率时，$(1-\pi_{y_t})$ 因子使梯度很小，避免破坏预训练知识
- **先验引导重分配**：概率质量按 $\pi_v$ 比例分配，高概率正确候选获得更多提升
- **隐式正则化**：一旦模型不再生成某错误回答，NSR 自然停止更新，防止过拟合

**实验证据**：NSR 训练过程中熵保持接近基础模型水平，Pass@256 达到 96.9（匹配基线），而 PSR 的 Pass@256 仅 91.2。Weighted-REINFORCE（$\lambda=0.1$，大幅降低 PSR 权重）在 MATH、AIME 2025、AMC23 上全面超越 PPO 和 GRPO。

## Implications

Group 4 论文将模型坍塌问题从"是否不可避免"转向"如何系统性解决"，Group 6 的 NSR 论文则进一步揭示了 RL 训练本身就是熵坍塌的重要来源，并提供了梯度层面的精确解释。综合来看，解决方案形成了四个层次：

1. **最小锚定**（R-Few）：1-5% 人类数据防止概念漂移，但仍依赖神经信号
2. **数据累积**（Breaking Curse）：保留真实数据作为锚点，理论保证误差有界，但存储成本线性增长
3. **分布保持**（ToEdit）：token 级编辑保护长尾分布，不增加数据量，理论保证避免坍塌
4. **梯度层面的长尾保护**（NSR）：通过仅惩罚错误回答（而非强化正确回答），在 RL 训练过程中按先验概率比例重分配概率质量，从梯度机制上防止分布收窄。W-REINFORCE（$\lambda=0.1$）证明只需大幅降低正样本权重即可兼顾准确性与多样性
5. **环境验证**（Absolute Zero）：可验证环境提供客观真理，但限制在特定领域

关键洞察：**模型坍塌的本质是分布漂移**。替换数据导致真实分布信息丢失，纯合成数据导致分布覆盖收窄，而 PSR 主导的 RL 训练则从梯度层面主动压缩分布。NSR 的发现尤其重要——它表明传统 RLVR 中的熵坍塌并非 RL 的固有缺陷，而是正样本强化（PSR）的副作用。"去除错误"比"强化正确"更能保护分布的丰富性，这与 ToEdit 保护低概率 token 的思路异曲同工：两者都是通过"减法"（去除错误/编辑高概率 token）而非"加法"（强化正确/生成新序列）来维持分布健康。

未来方向应探索"混合策略"：数据累积 + token 级编辑 + NSR 主导的 RL 训练 + 可验证环境，在不同场景下选择最优组合。

# 合成数据生成方法论的谱系：从教科书到智能体轨迹

Group 7 论文展示了至少五种截然不同的合成数据生成范式，每种方法在数据类型、生成成本、质量控制和适用场景上各有侧重。理解这些方法的差异和互补性，是构建高效数据合成流水线的关键。

## Evidence

### 方法一：教科书式生成（Phi 系列）

**核心思想**：让 LLM 生成结构化的教学内容——自然语言解释与代码/公式交织，像教科书一样清晰、自包含、有教学意义。

- Phi-1：GPT-3.5 生成 Python 教科书（< 1B tokens）+ 练习数据集（180M tokens），通过约束主题和目标受众实现多样性
- Phi-1.5：2 万个种子主题引导生成 20B tokens 的常识推理教科书，在 prompt 中使用网络数据样本增加多样性
- Phi-4：约 50 种合成数据集（4000 亿未加权 tokens），方法包括种子策划、重写增强、自我修订、指令反转、代码验证

**优势**：数据结构化程度高，推理链条线性，适合下一 token 预测学习。**局限**：多样性是核心挑战，需要精心设计种子策略；生成成本随质量要求上升。

### 方法二：渐进式进化（WizardLM Evol-Instruct）

**核心思想**：从简单指令出发，通过 LLM 驱动的迭代进化逐步增加复杂度和多样性。

- 5 种深度进化操作（添加约束、深化、具体化、增加推理步骤、复杂化输入）+ 1 种广度进化操作
- 每次仅增加"一点点"难度（10-20 个词），避免极端复杂指令
- 从 52K Alpaca 种子经 4 轮进化得到 250K 指令，使用 ChatGPT API 约 624K 次调用

**优势**：系统性地控制难度梯度，t-SNE 显示进化后指令分布比 ShareGPT 和 Alpaca 更均匀。**局限**：进化质量受限于执行进化的 LLM 能力上限；极高难度指令质量难以保证。

### 方法三：无模板自合成（Magpie）

**核心思想**：利用对齐 LLM 的自回归特性，仅输入预查询模板（无任何用户查询），让模型自动生成指令。

- 完全自动化，无需种子问题、提示工程或商业 API
- Magpie-Air（8B 生成）：300 万条，每千条 $0.12；Magpie-Pro（70B 生成）：100 万条，每千条 $1.1
- 支持多轮对话、偏好优化数据、领域特定和多语言数据

**优势**：成本极低，完全自动化，数据分布与真实用户请求一致。**局限**：数据质量受限于源模型能力；推理能力（数学/代码）方面表现不足。

**关键洞察**：Magpie 的反直觉发现——同族模型监督效果优于跨族强模型（如 Gemma2 系列监督 Gemma2-2B 优于 Llama-3-405B），这挑战了"越强的教师越好"的直觉。

### 方法四：迭代弱到强对齐（Nemotron-4 340B）

**核心思想**：弱模型生成数据训练强模型，强模型再生成更高质量数据，形成自增强飞轮。

- 第 1 轮：Mixtral-8x7B（弱）-> 生成数据 -> 对齐 340B -> 超越 Mixtral
- 第 2 轮：340B-Interm-1 -> 更高质量数据 -> 更强的 340B-Interm-2
- 三种偏好判断方式：Ground-Truth-as-Judge、LLM-as-Judge、Reward-Model-as-Judge
- Reward-Model-as-Judge 在 Chat-Hard 上远优于 LLM-as-Judge（87% vs 54%）

**优势**：可持续迭代提升，弱模型不构成学生模型的能力上限。**局限**：依赖初始种子模型的质量和多样性。

### 方法五：重述增强（Kimi K2 Rephrasing）

**核心思想**：通过风格和视角多样化的改写，将同一内容转化为多种表达形式，增加数据多样性而不引入新知识。

- 知识数据重述：分块自回归生成保持长文档全局连贯性 + 保真度验证
- 数学数据重述：改写为"学习笔记"风格 + 多语言翻译
- 实验证明：重述 10 次单轮训练（SimpleQA 28.94%）优于原始数据 10 轮重复训练（23.76%）

**优势**：不依赖新数据源，可直接提升现有数据的利用效率。**局限**：不增加知识量，仅增加表达多样性。

### 方法六：智能体轨迹合成（Kimi K2 Agentic Pipeline）

**核心思想**：在模拟和真实环境中生成工具使用示范数据，构建多样化的智能体交互轨迹。

- 三阶段流水线：工具规格生成（3000+ 真实 MCP 工具 + 20000+ 合成工具）-> 智能体与任务生成 -> 轨迹生成
- 结合模拟环境（可扩展性）和真实执行沙箱（可靠性）
- LLM 评判器根据任务标准过滤高质量轨迹

**优势**：生成的数据直接对应真实工具使用场景，可验证性强。**局限**：流水线复杂度高，需要大量工程投入。

### 方法七：对比强化学习数据生成（CUDA-L1）

**核心思想**：通过 RL 训练循环自动生成带性能反馈的代码优化数据，将性能对比信息嵌入训练信号。

- SFT 阶段：6 个模型生成 2,105 个成功 CUDA 代码样本
- 对比 RL 阶段：将多个 CUDA 变体及其性能分数嵌入 prompt，模型通过对比分析学习优化策略
- 桶采样策略确保对比样本的竞争性和多样性

**优势**：数据质量由可验证的性能指标（加速比）直接衡量。**局限**：仅适用于有明确性能指标的领域；奖励黑客是持续挑战。

### 方法八：文档间关联自举合成（SBP）

**核心思想**：标准预训练仅学习单文档内的 token 关联，忽略了文档间的语义关联。SBP 通过学习文档间的条件分布 $p(d_2 \mid d_1)$，从预训练数据自身自举合成新语料。

- 三步法：最近邻配对 → 合成器微调（条件生成）→ 大规模合成与联合训练
- 不依赖外部教师模型，合成器从预训练数据自身训练
- 贝叶斯解释：合成器隐式学习后验推断 $P(c \mid d_1)$，捕获标准预训练忽略的潜在概念信号
- 1T 规模实验，6B 模型恢复 oracle 改进的 58%

**优势**：自举式，不受外部教师能力上限；捕获被标准预训练忽略的结构信号。**局限**：计算开销大（最近邻搜索 + 大规模合成）；无法任意缩小规模。

### 方法九：实体图增强合成（EntiGraph）

**核心思想**：针对小规模领域语料，通过实体抽取和关系分析生成多样化合成数据，将多样性外化为实体图上的组合结构。

- 两步法：实体抽取 → 实体对/三元组关系分析
- 将 1.3M tokens 合成为 455M tokens，闭卷 QA 提升 16.73%
- 理论证明：准确率遵循混合指数增长，三阶段行为（线性→对数线性→饱和）
- 合成的参数化知识与 RAG 互补，组合后进一步提升

**优势**：多样性来自组合爆炸而非采样温度；不创造新知识，而是"重排"知识布局。**局限**：依赖外部 LLM 生成（GPT-4）；实体图组合爆炸在大语料上不可行。

### 方法十：精选蒸馏 + 解码控制（s1）

**核心思想**：用极少量（1K）精选蒸馏推理样本做 SFT，配合测试时 Budget Forcing 解码控制，激活预训练模型的潜在推理能力。

- 从 59K 候选中按质量×难度×多样性筛选 1K 样本
- Budget Forcing：阻止模型提前结束思考（追加 `Wait`）或强制结束思考
- 26 分钟训练（16×H100），AIME24 从 26.7% 到 56.7%
- 顺序式 test-time scaling 优于并行式 majority voting

**优势**：极低训练成本；数据选择而非数据量是关键。**局限**：顺序式扩展会饱和；Budget Forcing 的理论机制不明。

## Implications

1. **方法选择取决于目标任务的可验证性**：对于可验证任务（代码、数学），教科书式生成（Phi）和对比 RL（CUDA-L1）效果最佳，因为可以通过执行验证数据质量。对于开放域任务（对话、创意写作），无模板自合成（Magpie）和渐进式进化（WizardLM）更适合，因为它们能生成更自然的指令分布。

2. **方法之间存在互补性**：Phi-4 的实践表明，最优方案是多种方法的组合——约 50 种合成数据集覆盖不同方法。Kimi K2 同时使用重述增强（预训练）和智能体轨迹合成（后训练），也体现了多方法组合的趋势。

3. **成本-质量权衡的量化**：Magpie 每千条 $0.12-$1.1，WizardLM 需要 624K 次 API 调用，Phi-1 的合成教科书需要 GPT-3.5 大规模生成。随着开源模型能力提升（WizardLM 证明 LLaMA-2-70B-Chat 可替代 ChatGPT 作为进化执行器），合成数据的成本正在快速下降。

4. **多样性是所有方法的共同瓶颈**：Phi-1 通过随机约束（主题、受众、函数名）诱导多样性，WizardLM 通过广度进化增加主题覆盖，Magpie 依赖源模型的隐式指令分布，Kimi K2 通过重述增加表达多样性。没有一种方法完美解决多样性问题，这仍是合成数据生成的核心开放挑战。

5. **从"生成数据"到"生成课程"的演进**：Phi 系列的多阶段训练（先通用后专业）、SmolLM2 的四阶段数据混合调整、WizardLM 的渐进式难度进化，都指向同一个方向——合成数据生成不仅是"生成什么数据"的问题，更是"以什么顺序呈现数据"的课程设计问题。

6. **预训练阶段的新前沿——文档间关联合成**：SBP 和 EntiGraph 揭示了合成数据在预训练阶段的新方向——不是生成"更多"或"更好"的数据，而是通过合成来捕获标准预训练目标忽略的结构信号（文档间关联、跨实体知识连接）。这与后训练阶段的方法（释义、进化、自博弈）形成正交互补。SBP 的"自举"特性（从数据自身训练合成器，无需外部教师）尤其值得关注，它暗示了一条不依赖更强模型的合成数据路径。

7. **数据选择 vs 数据生成的辩证关系**：s1 用 1K 精选样本就激活了推理能力，而 SBP 用数百 B 合成 tokens 提升预训练性能。两者共同说明：**什么时候选数据、什么时候造数据，取决于能力是否已存在于模型中**。若预训练已赋予模型潜在推理能力，精选少量样本即可激活；若知识结构本身不完整（如缺少文档间关联），则需要合成新数据来补全。
